# CountPaper：个人记账功能路线图

## 原则

CountPaper 不使用 Beancount 或 Fava 的代码、语法或运行时。它继续以 `.countpaper` 纯文本文件为唯一真实数据；所有视图、索引、搜索历史和偏好均为可重建的派生状态。Fava 仅作为个人账本体验的参考，不追求文件或 API 兼容。

既有 0.1 格式仍是最小兼容层。预算、事件、查询等能力可作为 CountPaper 0.2+ 的明确版本扩展加入，旧文件不被自动重写。价格、商品、持仓与净值不属于本产品范围。

## 质量门槛

每个功能必须同时满足：

1. 对应格式扩展有版本化规范、示例和错误用例。
2. 纯 Swift 引擎具备单元/性能测试；大文件交互不在主线程全量解析。
3. 表单只作最小源文本补丁；失败时不损坏注释、空白或外部编辑。
4. macOS UI 有键盘操作、VoiceOver 标签、空状态、错误恢复与真实界面验证。
5. 功能完成前只生成签名的 `.app`；不创建 DMG、不宣传为发布版。
