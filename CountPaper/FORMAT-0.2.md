# CountPaper 0.2 纯文本格式

CountPaper 文件是 Markdown 风格的大纲。文件内容是唯一数据源；App 只负责编辑、生成和校验。

```markdown
---
format: countpaper/0.2
currency: CNY
---

@账户
- 资产:现金
- 资产:银行卡
- 收入:工资
- 费用:餐饮

# 2026-08-11
- 午餐
  - 时间: 12:35
  - 收款方: 星巴克
  - 标签: 咖啡, 日常
  - 费用:餐饮  32.50
  - 资产:现金  -32.50
```

规则：

- 文件必须以两条 `---` 包围的文件头开始，且包含 `format: countpaper/0.2` 与 `currency: CNY`。
- `@账户` 是账户区的专用标记，只能在文件头之后、第一条日期标题之前出现一次。其下每个账户以 `-` 开头；账户根级限于资产、负债、权益、收入、费用。
- 每个日期使用且只能使用一个一级标题 `# YYYY-MM-DD`；同一天的全部交易必须连续归入该标题，不能在文件其他位置再次声明相同日期。App 新增或移动交易时会维持这一结构；已有重复标题可通过“账本 > 合并重复日期标题”整理。
- 每笔交易以不缩进的 `- 摘要` 开始；可在摘要前加 `!`（待确认）或 `*`（确认）。
- 分录使用两个空格缩进的 `- 账户  金额`；每笔交易至少两条分录，金额代数和必须为零。
- 可选元数据也是交易下的缩进条目：`时间:`（英文模板使用等价的 `time:`，24 小时制 `HH:mm`）、`收款方:`、`标签:`、`链接:`。App 新录入的交易会记录精确到分钟的本地时间；旧交易没有时间时仍保持有效。
- 不支持 CountPaper 0.1 或其他旧格式；打开旧文件会提示格式错误，不会静默转换或修改原文。
