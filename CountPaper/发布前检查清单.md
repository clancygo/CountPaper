# CountPaper 发布前检查清单

本项目当前只生成 `.app`，不生成 DMG。下面的项目用于从“本机开发构建”进入“可公开分发的 macOS App”。

## 当前状态

- 已构建：`build/CountPaper.app`。
- 当前签名：ad-hoc（`TeamIdentifier=not set`）。
- 这足以用于当前 Mac 的开发和测试；不应作为对外公开下载的签名状态。

## 必须完成的外部发布门槛

- [ ] 使用拥有 Developer ID Application 证书的 Apple 开发者账号签名 `.app`。
- [ ] 通过 Apple 公证服务（notarization）提交并等待成功结果。
- [ ] 使用 `stapler` 将公证票据附加到 `.app`。
- [ ] 在未安装开发工具、未信任本项目的干净 macOS 用户环境中验证下载、首次打开、`.countpaper` 双击打开与默认应用设置。

这些步骤需要证书、Apple ID／App Store Connect 权限或 App 专用密码；它们不应被写入项目、命令历史或账本文件。

构建脚本支持两种无凭据落盘的模式：直接运行 `CountPaper/build-app.sh` 会使用 ad-hoc 签名；在证书已安装的发布机器上，以环境变量传入身份名称即可：

```sh
CODE_SIGN_IDENTITY='Developer ID Application: Your Name (TEAMID)' CountPaper/build-app.sh
```

如发布需要显式 entitlements，可额外传入已审核的 entitlements 文件路径：`CODE_SIGN_ENTITLEMENTS=/absolute/path/to/entitlements.plist`。

签名完成后，使用下面的预检脚本确认 app 不再是开发签名：

```sh
zsh CountPaper/release-preflight.sh CountPaper/build/CountPaper.app
```

## 发布前功能回归

- [ ] 新建、打开、保存、另存为、自动保存和关闭未保存提示。
- [ ] 从 Finder 双击 `.countpaper`，以及“设为默认打开应用”。
- [ ] 支出、收入、转账、账户、预算、对账、事件、账户备注和交易链接。
- [ ] 原文编辑、撤销、查找、跳转到行、缩进、命令面板和格式速查。
- [ ] 概览、日记账字段／状态筛选、账户流水跳转、收支报表和 CSV 导出。
- [ ] 外部修改自动重载与冲突保护。
- [ ] 至少一万笔交易账本的解析性能回归。

## 已验证的工程命令

```sh
DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer \
  xcrun swiftc -O -framework Cocoa -module-cache-path CountPaper/build/module-cache \
  CountPaper/CountPaper.swift CountPaper/Tests/LedgerParserTests.swift \
  -o /private/tmp/LedgerParserTests && /private/tmp/LedgerParserTests

CountPaper/build-app.sh
codesign --verify --deep --strict --verbose=2 CountPaper/build/CountPaper.app
```

日常回归可简化为一条命令：

```sh
zsh CountPaper/verify.sh
```

## 不在本发布目标内

不添加 DMG、账户系统、自建同步、私有账务数据库、投资/价格/持仓/净值、多币种、导入、OCR、附件或多人协作。
